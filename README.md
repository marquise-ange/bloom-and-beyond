# Bloom & Beyond 🌿

A reusable Tailwind CSS component library inspired by nature. Bloom & Beyond demonstrates consistent, accessible, and reusable UI components, including buttons, alerts, product cards, and profile cards.

## 🌱 Project Overview

Bloom & Beyond is a component library created to practice building reusable UI elements with Tailwind CSS. It uses a botanical theme with natural green colors, a clean layout, and consistent styling.

## ✨ Features

### 1. Reusable Buttons
- **Primary button:** Highlights important actions.
- **Secondary button:** Provides an alternative action.
- **Outline button:** Offers a simple outlined style.
- **Disabled button:** Demonstrates an unavailable action.
- Hover and transition effects for interactive feedback.

### 2. Alert Components
Four reusable alert styles communicate different messages:
- **Success:** Confirms a successful action.
- **Warning:** Displays a reminder or caution.
- **Error:** Communicates that something went wrong.
- **Information:** Shares helpful tips.

### 3. Reusable Cards
- **Product card:** Displays a Monstera Deliciosa plant, image, description, and price.
- **Profile card:** Introduces a plant care specialist with a profile image and description.

### 4. Responsive Design
- Uses Tailwind CSS utility classes to create flexible layouts.
- Uses responsive breakpoints for different screen sizes.
- Includes a sticky navigation header for easy navigation.

### 5. Accessibility
- Uses semantic HTML elements.
- Includes descriptive image alternative text.
- Uses appropriate ARIA roles for alert messages.
- Includes accessible labels for decorative SVG icons.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Visual Studio Code (recommended)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rithairagena13-spec/bloom-and-beyond.git
   ```

2. Open the project folder:

   ```bash
   cd bloom-and-beyond
   ```

3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Build the Tailwind CSS output:

   ```bash
   npm run build
   ```

5. Open `index.html` with the VS Code Live Server extension.
